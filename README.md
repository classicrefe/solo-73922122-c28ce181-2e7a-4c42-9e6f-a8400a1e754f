# 水位时长核算系统

水文年报场景：调查范围确定前无法固定警戒水位，因此本系统**导入时只保存逐日摘要**，
警戒水位在查询时以任意整数毫米临时给出，查询全程只读摘要、不改数据。

## 核算规则

1. 导入单站、按时间有序的 CSV：UTC 整秒时间戳（`...Z` 或 `+00:00`），水位为整数毫米。
2. 相邻观测间隔 **≤ 1 小时**：段内按直线（线性）估算水位；**> 1 小时**：整段判未测，不插值。
3. 跨午夜的观测段按两个 UTC 日的实际占秒分摊；统计口径为 UTC 自然日，每天固定 86400 秒。
4. 数据库只保存逐日摘要，原始观测不落库。
5. 同一站任一天与已有摘要重叠即**整批退回**（单事务回滚），原摘要保持不变。
6. 查询选择日期范围并填写任意整数毫米警戒线，输出：
   - 达到或超过警戒线的累计秒数（**恰好等于警戒线的平水段算达标**）；
   - 区间内有测秒数、未测秒数，并附逐日明细；
   - 无任何摘要的日期按全天未测列示。
7. 改变警戒线只是新的只读查询，不会重新导入或修改摘要。

## 摘要如何支持任意警戒线（设计要点）

每张摘要表按“站 × UTC 日”保存：

- `daily_summary`：有测秒数、未测秒数、日内插值最低/最高水位；
- `daily_level_tail`：每个整数毫米 `h` 的尾分布秒数 `tail(h) = 当日水位 ≥ h 的秒数`，
  由各线性段按比例精确累加（浮点秒，展示保留 3 位小数）。

查询警戒线 `h` 时：日内最低水位 ≥ `h` → 整个有测时段达标；日内最高水位 < `h` → 0；
其余情况直接读 `tail(h)`。因此无需原始观测即可回答任意整数警戒线。

## 目录结构

```
app/            Flask 应用（db / importer / query / web + templates）
tests/          pytest 用例（18 项，覆盖解析校验、线性/平水/跨午夜/未测、
                重叠整批退回、警戒线边界与网页端到端流程）
scripts/        示例 CSV 生成脚本
samples/        演示 CSV（由脚本生成）
Dockerfile, docker-compose.yml, docker/entrypoint.sh
wsgi.py         gunicorn 入口
```

## Docker Compose 启动

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

SQLite 数据库位于命名卷 `waterlevel-data` 内的 `/data/waterlevel.db`，容器重建不丢数据。

## 本地（无 Docker）运行

```bash
pip install -r requirements.txt
python scripts/generate_samples.py          # 生成 samples/s001_waterlevel.csv
flask --app wsgi:app init-db                # 可选，首次访问也会自动建表
flask --app wsgi:app run --port 8000
```

## 网页演示流程

1. 打开“导入观测 CSV”，站码填 `S001`，选择 `samples/s001_waterlevel.csv` 导入。
   示例含跨午夜线性段、平水段（120mm）、5400 秒未测缺口、上升段和下降段。
2. 再次提交同一文件，页面提示“与已有摘要重叠……整批退回”，摘要不增加。
3. 打开“警戒线核算查询”，站码 `S001`、日期 `2026-01-01` 至 `2026-01-02`：
   - 警戒线 120mm → 达标 1,800 秒（平水段；端点瞬时值不计时长）；
   - 警戒线 110mm → 达标 2,700 秒（900 秒跨午夜段 + 1,800 秒平水段）。
4. 把日期延到 `2026-01-03`，无数据那天按 86,400 秒未测列示。

```bash
python -m pytest tests/ -q
```

## CSV 格式

```csv
timestamp_utc,level_mm
2026-01-01T23:30:00Z,100
2026-01-02T00:00:00Z,120
```

表头可选；空行跳过；时间戳必须严格递增；拒绝小数秒、非 UTC 时区、非整数水位。
